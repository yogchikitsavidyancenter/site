# Yog Chikitsa Vidyan Center website

Plain HTML, CSS and JavaScript. No build step.

## Deploy on GitHub Pages
1. Create a GitHub repo and push all these files to the `main` branch.
2. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. Your site goes live at `https://<username>.github.io/<repo>/` within a minute or two.
